Coding Keyboard.

An iOS keyboard laid out the way a desktop keyboard is laid out. In landscape and on iPad, the top four rows are identical to a full-size keyboard, key for key — so you already know where everything is.

In review on the App Store iPhone & iPad iOS 18.6+ Free · MIT

The stock iPhone keyboard hides the braces, brackets, backslash, pipe, backtick and tilde behind two levels of page switching, and has no Tab key at all. This one puts them on the first layer and prints every shifted value on the key that produces it.

Terminal mode adds esc, ctrl and opt and a full set of cursor keys, and sends the bytes a real keyboard would have sent — ⌃C is one byte, 0x03 — so a shell cannot tell the difference.

It does not request Full Access. Without it, iOS grants a keyboard extension no network capability at all: it cannot send your keystrokes anywhere because it cannot send anything anywhere.

No autocorrect, no predictive text, no swipe typing, no emoji key. US ASCII only.
